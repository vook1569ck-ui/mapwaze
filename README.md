# ماب وايز العراق + Supabase
1. افتح https://supabase.com/ من Safari وسجّل حساباً وأكّد البريد.
2. أنشئ مشروعاً جديداً باسم mapwaze-iraq، وضع كلمة مرور قوية لقاعدة البيانات واحفظها، واختر منطقة متاحة قريبة.
3. بعد جاهزية المشروع افتح SQL Editor > New query. انسخ كامل ملف supabase_setup.sql والصقه ثم Run.
4. افتح Connect أو Settings > API Keys. انسخ Project URL وPublishable key الذي يبدأ بـ sb_publishable_. لا تضع Secret key أو service_role في الموقع.
5. ارفع كل الملفات داخل ZIP إلى جذر https://github.com/vook1569ck-ui/mapwaze عبر Add file > Upload files، ثم Commit changes.
6. افتح https://vook1569ck-ui.github.io/mapwaze/ واضغط «إعداد البلاغات المشتركة»، ثم أدخل Project URL وPublishable key واضغط حفظ وربط.
البلاغات العامة تسمح بالقراءة والإضافة فقط، ولا تسمح بالحذف/التعديل العلني. النسخة لا تملك بعد تسجيل دخول أو حماية كاملة من البلاغات المزعجة؛ أضف ذلك قبل إطلاق واسع. الخريطة والبحث والمسارات تعتمد على خدمات عامة وتحتاج الإنترنت.
