# ماب وايز العراق — النسخة الكاملة التجريبية

## المزايا
- خريطة تفاعلية للعراق.
- البحث عن الأماكن داخل العراق.
- تحديد موقع الجهاز.
- حساب مسار قيادة وإظهار المسافة والوقت التقريبي.
- تعليمات اتجاهات عربية وقراءتها صوتياً.
- بلاغات محلية للحوادث والازدحام والطريق المغلق والخطر ونقاط التفتيش.
- حفظ الوجهات محلياً ومشاركة رابط الموقع.
- PWA قابلة للإضافة إلى الشاشة الرئيسية، مع تخزين ملفات الواجهة الأساسية.

## نشر على GitHub Pages
1. فك ضغط الملف ZIP.
2. افتح مستودع GitHub `mapwaze`.
3. اختر Add file ثم Upload files.
4. ارفع **كل الملفات الموجودة داخل المجلد** دفعة واحدة إلى جذر المستودع (لا ترفع مجلد المشروع نفسه ولا ملف ZIP فقط).
5. وافق على استبدال `index.html` و`manifest.webmanifest` و`sw.js` إذا طلب GitHub، ثم Commit changes.
6. انتظر اكتمال Pages وافتح رابط الموقع، ثم أغلق النسخة المثبتة وافتحها مجدداً.

## حدود مهمة
- هذه نسخة واجهة كاملة قابلة للتجربة، لكنها ليست بعد تطبيقاً أصلياً في App Store أو Google Play.
- بلاغات الطريق والمحفوظات تُخزن على الجهاز نفسه فقط. لا توجد قاعدة بيانات أو حسابات أو مزامنة بين المستخدمين؛ يلزم خادم/Backend وقاعدة بيانات لإضافة البلاغات المشتركة.
- لا يوجد مصدر بيانات زحام مباشر؛ المسار والوقت تقديريان.
- البحث يعتمد على Nominatim، والمسارات على OSRM العام، والخرائط على OpenStreetMap. هذه خدمات عامة قد تتأخر أو تضع حدوداً على الاستخدام، وليست مضمونة التشغيل دائماً.
- يحتاج البحث والملاحة والخريطة إلى الإنترنت. تخزين الواجهة لا يعني تنزيل خرائط العراق للاستخدام دون إنترنت.
- لا تستخدم الهاتف بيدك أثناء القيادة. استخدم التوجيه الصوتي بأمان.
