# MapWaze Iraq — تحديث البلاغات

## نشر التحديث
1. شغّل ملف `supabase_setup.sql` كاملاً في Supabase > SQL Editor > Run. هذا يضيف جدول تأكيدات البلاغات وسياسات RLS، ويعيد إنشاء السياسات المطلوبة بأمان.
2. ارفع جميع ملفات ZIP إلى جذر مستودع GitHub عبر Add file > Upload files ثم Commit changes.
3. افتح الموقع وحدّث الصفحة. إعدادات Supabase المخزنة محلياً ينبغي أن تبقى محفوظة في نفس المتصفح.

## التحسينات
- منع تكرار بلاغ من النوع نفسه خلال 30 دقيقة وضمن 250 متر على واجهة التطبيق (حماية مساعدة وليست ضماناً ضد كل التكرار).
- زر تأكيد للبلاغات المشتركة، مع حد فريد لكل report_id/device_id على الجهاز نفسه.
- عرض عدد التأكيدات.

## ملاحظات
- هذه ليست حماية كاملة من إساءة الاستخدام: هوية الجهاز محلية ويمكن التحايل عليها. قبل إطلاق عام أضف تسجيل دخول ومراجعة/معدل إرسال على الخادم.
- لا يتم حذف البلاغات المشتركة تلقائياً من قاعدة البيانات؛ التطبيق يعرض البلاغات الحديثة فقط. يلزم تنظيف مجدول أو سياسة صلاحية مستقبلية إذا أردت حذفاً فعلياً.
- لا ترسل Secret key أو service_role إلى الواجهة.
